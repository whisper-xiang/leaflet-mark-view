## 详细介绍

直接整段粘贴到 Store listing → Detailed description：

```
在 Chrome 里安静地读你的 Markdown。打开本地文件夹、单篇文章或 GitHub 仓库，拖进来就能读。解析、公式、流程图都在浏览器本地完成，不上传文件。

打开方式
• 工具栏图标：选择阅读当前网页，或打开阅读器后选文件夹、Markdown 文件、GitHub / .md 链接
• 普通网页右键「用 Leaflet 阅读当前网页」或按 Alt+Shift+M（Mac：Option+Shift+M），本机提取正文转成 Markdown
• 把文件夹或 .md 拖进阅读器
• 将 Chrome 设为 .md 的默认应用，并开启「允许访问文件网址」，即可双击用本扩展打开

阅读
• 局域网分享：同一 Wi-Fi 只读查看当前文档。访客页沿用侧栏、搜索、主题和大纲，目录边缘可拖拽。文件留在本机，首次使用需安装本机分享组件
• 章节折叠：标题左侧箭头收起该节；一级标题和二级标题都能单独收起，只有一个文档标题时从二级章节开始收起
• 文中的 style 与行内样式按原文显示；表格最右侧列边也可拖动
• 自动滚动：5–200 像素/秒调速、暂停/继续、到底循环，速度偏好自动保存
• 侧栏文件树、全文搜索（Ctrl/⌘ K）、大纲、最近阅读、阅读位置记忆
• 浅色 / 羊皮纸 / 青纸 / 深色 / 夜墨，黑体或宋体，四档字号
• GFM 表格、任务列表、脚注、代码高亮
• KaTeX 公式、Mermaid、PlantUML 均本地渲染，点击图片或图表可放大

导出
• 复制带样式的 HTML，粘贴到公众号、飞书、邮件
• 导出 A4 Word（.docx）
• 转为 Confluence Wiki Markup

隐私
• 无账号、无统计、无广告
• 必选权限为 storage，以及仅在打开局域网分享时使用的 nativeMessaging；GitHub 预授权；其他网站按需授权
• 阅读记录只保存在本机

需要 Chrome 116 或更高版本。本地文件夹依赖 File System Access API。用 Chrome 直接打开磁盘上的 .md 时，请在扩展详情中开启「允许访问文件网址」。

项目主页：https://whisper-xiang.github.io/leaflet-mark-view/
更新说明：https://github.com/whisper-xiang/leaflet-mark-view/releases
隐私政策：https://whisper-xiang.github.io/leaflet-mark-view/privacy.html
```
