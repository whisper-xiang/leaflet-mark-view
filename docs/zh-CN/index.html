安装说明

需要 Chrome 或 Edge 116 及以上。下载 Release 压缩包后，在扩展页以开发者模式加载。

下载并解压

打开 Releases，下载 leaflet-mark-view.zip，解压到任意目录。

加载已解压的扩展

打开 chrome://extensions/，开启右上角「开发者模式」，点击「加载已解压的扩展程序」，选择解压后的文件夹。

允许访问文件网址

在扩展详情页开启「允许访问文件网址」。不开启则无法拦截本机 .md，也无法读取同目录图片。

从源码加载
git clone https://github.com/whisper-xiang/leaflet-mark-view.git

将 Chrome 设为 .md 的默认应用后，双击文件即可用本扩展打开。详细步骤见 GitHub README。无账号、无统计、无广告，阅读记录只保存在本机。隐私说明见 PRIVACY.md。
