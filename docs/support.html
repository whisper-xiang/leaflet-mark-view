帮助与支持 / Help & support

Leaflet Mark View 是一款在 Chrome 中阅读 Markdown 与网页正文的扩展，由轻语维护。

反馈问题

通过 GitHub Issues 联系维护者、报告问题或提出建议。查看已有问题无需登录，提交新问题需使用 GitHub 账号。

请注明 Chrome 版本、扩展版本、操作步骤以及错误提示。网页转换问题可附公开文章链接；请勿附上密码、访问令牌或私人文档。

安装与升级

从 GitHub Releases 下载 leaflet-mark-view.zip 并解压。在 chrome://extensions 开启开发者模式，选择「加载已解压的扩展程序」。升级时替换原目录文件，再点击扩展卡片上的「重新加载」。

常见问题

右键菜单没有出现或快捷键不生效

确认加载的是更新后的目录，并在 chrome://extensions 重新加载。回到普通 HTTP/HTTPS 文章页，右键选择「用 Leaflet 阅读当前网页」。默认快捷键为 Alt + Shift + M，Mac 为 Option + Shift + M；可在 chrome://extensions/shortcuts 检查或修改。

网页无法转换

等待正文加载完成后再转换。浏览器内置页、扩展商店、PDF 和没有正文的页面不支持。只转换当前已加载的正文，不读取未展开内容或跨域嵌入页面。图片可能受原网站的访问限制。

自动滚动如何暂停

手动滚动可暂停。Esc 优先关闭当前弹框或菜单，没有弹框时暂停滚动。速度与到底循环选项位于阅读器顶栏的自动滚动面板。

本地 Markdown 文件不能直接打开

在扩展详情页启用「允许访问文件网址」。也可通过阅读器内的 Open 菜单选择文件或文件夹。

如何删除网页摘录

在「最近阅读」中移除记录会删除对应摘录。最近阅读最多保留 20 条，超出上限会清理旧记录。卸载扩展或清除浏览器中该扩展的数据可删除本地存储。详见隐私政策。

English support

Leaflet Mark View is maintained by Qingyu (轻语). Report bugs and request features through GitHub Issues. Include your Chrome version, extension version, reproduction steps, and any error message. Do not include passwords, tokens, or private documents.

For unpacked installations, replace the installed files with the latest release and reload the extension at chrome://extensions. Capture a normal article using the toolbar popup, the webpage context menu, or Alt + Shift + M (Option + Shift + M on macOS). Configure shortcuts at chrome://extensions/shortcuts.

Browser pages, the extension store, PDFs, and pages without article text cannot be converted. Captures are processed and stored locally. See the bilingual privacy policy for details.
